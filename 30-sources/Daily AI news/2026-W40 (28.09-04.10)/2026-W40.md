## Agents and developer tools
- **Anthropic launched mods for Claude Code: TypeScript hooks into the agent loop (Oct 1)** — A mod can rewrite a prompt before it reaches the model, block or retry a tool call, approve or deny a permission request, redact secrets from tool output, and replace interface elements. Mods ship inside plugins (installed with `/plugin`), run as a middleware chain in load order, and are not sandboxed: they have the same machine privileges as Claude Code. Anthropic rebuilt its own diff pane, agents.md loader and telemetry as mods. ([report](https://postcutoff.com/e/2026-10-01-claude-code-mods/), [guide](https://www.developersdigest.tech/blog/claude-code-mods-guide-2026), [security note](https://www.remio.ai/post/claude-code-mods-arrive-but-custom-ui-comes-with-full-machine-access)) `anthropic-claude-code-mods-release`
