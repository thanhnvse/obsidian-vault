# AI news — 2026-10-20

> Collected by the daily-ai-news routine. Draft: not verified, not in my own words.

## Models
- **Mistral ships Voxtral 3, a speech-in and speech-out suite** — Three transcription models (Small, Mini 4B batch, Mini Realtime under 500 ms) and a TTS model covering 35+ languages, priced from $0.0035/min for batch transcription and $13 per 1M characters for speech; a voice-agent API runs at $0.04/min with Mistral Small 4. It gives agent builders a single-vendor, self-hostable voice stack. ([source](https://mistral.ai/news/voxtral-3/)) `mistral-voxtral-3-release`

## Agents and developer tools
- **Google open-sources TorchTPU to run native PyTorch on TPUs** — PyTorch apps move to TPUs with a configuration change instead of a rewrite, with integration work for Hugging Face, vLLM and SGLang, plus a "TPU agent suite" that ports code and fixes errors. It lands one day after AWS's TorchNeuron, so both hyperscalers now attack Nvidia's developer lock-in at the framework layer. ([source](https://cloud.google.com/blog/topics/ai-infrastructure/torchtpu-is-now-open-source-run-native-pytorch-on-tpus), [source](https://techcrunch.com/2026/10/20/google-has-joined-amazon-in-attacking-nvidias-stronghold-with-ai-app-developers/), [agent suite](https://github.com/google-pytorch/tpu-agent-suite)) `google-torchtpu-open-source`
- **DeepSeek open-sources DeepInfer, its production inference engine** — Apache 2.0, built mainly on vLLM, targeting DeepSeek-V4.1-Flash on Nvidia SM100 GPUs and Huawei Ascend 950 NPUs. The release leaves out the KV-cache system, prefill/decode disaggregation and data-parallel load balancing, so it is not a complete serving stack. ([source](https://github.com/deepseek-ai/DeepInfer)) `deepseek-deepinfer-open-source`
- **Zillow launches a Claude connector for home search** — Users can search listings, run affordability calculations and book tours inside Claude; Zillow says no user data flows to Anthropic. Another large consumer brand shipping a connector rather than its own chatbot. ([source](https://www.unite.ai/zillow-launches-claude-connector-for-listings-tours-and-financing/)) `zillow-claude-connector-launch`
- **MIT CSAIL leaves Claude agents on a virtual island for 30 hours** — Isolated Claude Opus 4.7 instances invented games and set juggling records without being asked; the researchers warn this may be role-play rather than play. ([source](https://www.technologyreview.com/2026/10/19/1147095/ai-stranded-claude-virtual-desert-island-play/)) `mit-csail-claude-island-study`
